Sistema de Caja / Punto de Venta para Supermercado
Aplicación web que permite registrar ventas rápidamente, gestionar el flujo de caja y emitir comprobantes básicos. Diseñado para ser simple, rápido y usable por personal de caja sin experiencia técnica.

Funcionalidades principales
✅ Registro de ventas en tiempo real  
✅ Cálculo automático de subtotales, IVA / impuestos y total  
✅ Agregado y eliminación de productos del carrito  
✅ Control de medios de pago (efectivo, tarjeta, etc.)  
✅ Vuelto automático  
✅ Historial de ventas por día  
✅ Apertura y cierre de caja  
✅ Impresión / descarga de ticket  

Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage
- DOM API (100% frontend)
- (Opcional) Fetch API para integración con stock

Objetivo del sistema
- Agilizar el cobro en línea de caja
- Minimizar errores humanos al dar vuelto
- Llevar registro de ventas diarias
- Conocer el dinero real en caja

Cómo utilizar
1. Seleccionar producto desde buscador o código de barras
2. Agregar al carrito de venta
3. Elegir medio de pago
4. Confirmar venta
5. Guardar ticket (opcional)
